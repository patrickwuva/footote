FOOTNOTE

How to dig

  1. Seven prompts a day, the same for everyone. Each asks for something from American history.
  2. You have 25 seconds per prompt. Suggestions appear as you type; Enter digs the highlighted one. Anything not in the record costs 3 seconds, and you keep going.
  3. Obvious answers barely move you. Rare ones send the lantern deeper. Every point is a year back in time.
  4. Every prompt hides one answer almost nobody gives. Find it and it's Lost to History: 100 years in one drop.

Unlimited plays the same way, with a fresh set of seven prompts every run. Answers on the reveal screen link to Wikipedia if you want to read more.
